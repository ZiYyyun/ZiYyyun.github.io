这是第一篇测试笔记。

当前流程：

- 在 Obsidian 中写 Markdown。
- 把笔记同步或复制到 `src/content/blog`。
- 推送到 GitHub。
- GitHub Actions 自动构建并发布到 GitHub Pages。

后面可以再加 frontmatter 自动补全、标签、目录、双链转换和图片附件处理。
